# Managed local runtime data (not versioned)

Only this guide is tracked. Future runtime folders: `raw/`, `normalized/`, `display/`, `tmp/`, `metadata/`, and `exports/`. All content beneath this directory is ignored by Git apart from the guide.

No climate data has been downloaded. The proposed manager caps occupancy at 90 decimal GB within an approximate 100 GB budget. Ignored files are not protected by source-code commits; snapshots/manifests and database backups need their own retention plan.
